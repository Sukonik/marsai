# MARSAI brand assets

Official logo mark: planet-and-orbit emblem inside a shield.

| File | Use |
| --- | --- |
| `marsai-mark.png` / `.webp` | Master mark, 1254×1254 |
| `marsai-mark-512.png`, `-192.png` | Manifest / app icons |
| `marsai-mark-180.png` | Apple touch icon |
| `marsai-mark-32.png`, `favicon.ico` | Browser favicon |

These PNG, WebP, and `.ico` files are the raster mark and favicon set. The vector emblem, wordmarks, subtag, and lockups live in [`public/brand/`](../../public/brand/) and are documented in [`docs/LOGO_HANDOFF.md`](../../docs/LOGO_HANDOFF.md). The emblem SVGs are approved; the rounded path wordmarks and combined lockups are **deprecated** (see the logo handoff). Until the replacement wordmark ships, pair the emblem with live Orbitron text reading MARS AI. A brand zip is still to come. Version history is in [`CHANGELOG.md`](../../CHANGELOG.md).
